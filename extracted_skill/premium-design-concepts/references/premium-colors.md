## Color Application Rules

### 60-30-10 Rule
- 60% Primary/Background color
- 30% Secondary/Support color
- 10% Accent/Action color

### Contrast Ratios
- Headlines on background: 7:1 minimum
- Body text on background: 4.5:1 minimum
- Interactive elements: 3:1 minimum

### Gradient Combinations
```css
/* Luxury Gradient */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Tech Gradient */
background: linear-gradient(90deg, #00d2ff 0%, #3a47d5 100%);

/* Organic Gradient */
background: linear-gradient(120deg, #f6d365 0%, #fda085 100%);

/* Dark Gradient */
background: linear-gradient(180deg, #0f0c29, #302b63, #24243e);
```

### Color Psychology

**Black (#000000)**
- Sophistication, luxury, power
- Use for: Premium products, high contrast

**Gold (#D4AF37)**
- Wealth, success, achievement
- Use for: Accents, CTAs, premium tier

**Navy (#1E3A5F)**
- Trust, stability, professionalism
- Use for: Corporate, financial, healthcare

**White (#FFFFFF)**
- Purity, simplicity, space
- Use for: Minimal design, breathing room

**Electric Blue (#0099FF)**
- Innovation, technology, future
- Use for: Tech products, CTAs, links
